# Pangasinan Heritage Digital Showcase — Activity 1.1
A Next.js 14 App Router project implementing a mobile-first Atomic Design component library.

## Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Structure
- `app/` — Next.js app shell and page
- `components/atoms/` — Button, Typography, Color Tokens, Icon, Image
- `components/molecules/` — Heritage Card, Search Form, Navigation Item
- `components/organisms/` — Heritage Grid, Header Navigation

No `node_modules` or generated build output is included.
## Image sources
The showcase uses publicly accessible tourism images from Pangasinan tourism/travel pages for the visual demonstration. The destination links point to local-government or tourism information pages where available.
